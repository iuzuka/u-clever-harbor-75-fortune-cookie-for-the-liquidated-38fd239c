Entry for the [make.fun bounty `u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c`](https://make.fun/bounty/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c).

A single fortune-cookie line (at most 20 words) for a crypto trader who has
just been liquidated — oracular fortune voice, the loss in it, and a
punchline that lands on the trader's empty wallet.

Want to run your own bounties? [Join make.fun with my referral](https://make.fun/r/9p6337rb).

## Run

```sh
python3 main.py
```

## Output

Writes the fortune line to `/output/entry.txt` (falls back to
`./output/entry.txt` if `/output` is not writable).

Final line (13 words, 85 characters):

> A great fortune awaits you — unfortunately, it is currently in someone else's wallet.
